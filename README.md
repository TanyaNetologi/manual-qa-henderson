# Manual QA — Henderson

Учебный проект по ручному тестированию веб-приложения Henderson.

Цель проекта — продемонстрировать навыки тест-дизайна, подготовки тестовой документации, поиска дефектов и оформления баг-репортов.

## Что выполнено

- составлен чек-лист по основным пользовательским сценариям;
- разработаны тест-кейсы для формы регистрации;
- выполнены позитивные и негативные проверки;
- проверены граничные значения;
- проверено подтверждение регистрации по коду;
- оформлены баг-репорты по найденным дефектам;
- определена Severity дефектов;
- оформлены Steps to reproduce, Actual Result и Expected Result;
- найденные дефекты дополнительно оформлены в GitHub Issues со скриншотами.

- уведомлений;
- выхода из аккаунта;

- приоритетов проверок.

## Тест-кейсы

[Открыть тест-кейсы](./manual_qa_henderson_test_cases_portfolio.xlsx)

Представлены проверки:

- валидного номера телефона;
- невалидных данных;
- граничных значений;
- обязательных полей;
- согласия на обработку персональных данных;
- отправки кода подтверждения;
- валидного и невалидного кода;
- повторной отправки кода.

## Баг-репорты

[Открыть баг-репорты](./manual_qa_henderson_bug_reports_portfolio.xlsx)

В проекте оформлены дефекты:

- нерелевантные результаты поиска;
- некорректный расчёт скидки;
- некорректное состояние авторизации пользователя.

Для каждого дефекта указаны:

- Summary;
- Severity;
- Environment;
- Preconditions;
- Steps to reproduce;
- Actual Result;
- Expected Result;
- Attachment.
