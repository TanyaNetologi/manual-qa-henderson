# Manual QA — Henderson

Учебный проект по ручному тестированию веб-приложения Henderson.

В проекте представлены примеры тестовой документации, подготовленной в рамках обучения QA.

## Что выполнено

- разработаны тест-кейсы для формы регистрации;
- выполнены позитивные и негативные проверки;
- проверены граничные значения;
- проверено подтверждение регистрации по коду;
- оформлены баг-репорты по найденным дефектам;
- определены Severity для дефектов;
- описаны Steps to reproduce, Actual Result и Expected Result.

## Тест-кейсы

Файл:

`manual_qa_henderson_test_cases_portfolio.xlsx`

Содержит проверки:

- валидного номера телефона;
- невалидных данных;
- граничных значений;
- обязательных полей;
- согласия на обработку персональных данных;
- кода подтверждения;
- повторной отправки кода.

## Баг-репорты

Файл:

`manual_qa_henderson_bug_reports_portfolio.xlsx`

Содержит примеры дефектов:

- некорректная работа поиска;
- неправильный расчёт скидки;
- проблема с авторизацией пользователя.

Для каждого дефекта указаны:

- Summary;
- Severity;
- Environment;
- Description;
- Steps to reproduce;
- Actual Result;
- Expected Result;
- Attachments.
